## Funcionalidades Principales

### 1. Registrar Calificaciones
* **Acceso:** Menú Principal -> `Registrar Notas`.
* **Matriz Académica:** Presenta la nómina de estudiantes asignados por curso y paralelo.
* **Componentes de Evaluación:** Permite ingresar notas de 0.00 a 10.00 en los tres componentes del Ministerio:
  - **Aportes (40%)**
  - **Proyecto (30%)**
  - **Evaluación (30%)**
* **Guardar:** Presionar `Guardar Notas` para actualizar inmediatamente las calificaciones en la API REST.

### 2. Crear Tareas y Actividades
* **Acceso:** Menú Principal -> `Crear Tarea`.
* **Publicación:** Completar título, descripción, tipo de actividad y fecha límite de entrega.

### 3. Control de Asistencia Diaria
* Registrar los estados: `PRESENTE`, `ATRASO`, `FALTA_INJUSTIFICADA`.
